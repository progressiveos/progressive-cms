# Figma → тема Progressive CMS

Дизайн живёт в Figma — тянем его в движок через REST API (Personal Access
Token). Официальный «Dev Mode MCP server» — локальный сервер внутри Figma
десктопа (`127.0.0.1:3845`), на серверном агенте работать не может; community
MCP-обёртки дергают тот же REST — поэтому идём в REST напрямую, без лишнего
звена.

## Подготовка (один раз)

1. Figma → Settings → Security → **Personal access tokens** → сгенерировать.
2. Токен — только через окружение: `export FIGMA_TOKEN=…` (никогда в argv/git).

## Pull

```bash
cms figma pull --url "https://www.figma.com/design/<key>/Name?node-id=12-345" \
  --out-dir ./figma-out
```

`node-id` — необязателен: без него берутся все топ-фреймы файла, с ним —
один фрейм. Выход:

- `tokens.css` — черновик дизайн-токенов: палитра (частотность) +
  типографика как CSS custom properties;
- `frames/*.png` — отрендеренные фреймы (scale 2×) — визуальный референс
  при сборке темы;
- `report.json` — сводка + next steps.

## Маппинг в тему

1. Свести палитру из `tokens.css` с токенами темы (`theme.json` →
   переменные `--theme-*`); цвета-дубли склеить, семантизировать имена
   (`--figma-color-1` → `--theme-primary` и т.п.).
2. Типографику — в токены шрифтов темы (font-family/размеры/веса).
3. `frames/*.png` держать открытыми как референс при вёрстке блоков;
   расхождение проверять скриншотами своей сборки (браузерный рендер).

## Границы

- **Variables API** (`/variables/local`) — только Enterprise (403 на Pro):
  токены собираются из fill/text **styles** и фактических заливок узлов —
  этого достаточно для черновика.
- Rate limit ~30 req/min; огромные файлы могут отдать 400 — бери `node-id`.
- Токен PAT открывает все файлы этого пользователя — хранить как секрет,
  не коммитить, отзывать после проекта.
