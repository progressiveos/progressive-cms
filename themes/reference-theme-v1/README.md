# reference-theme-v1

First-party reference theme (M03). Proves the Progressive CMS Theme Contract v1:
all 17 mandatory Content blocks, header/footer navigation placements
(desktop/tablet/mobile), design tokens, typed Theme Settings, media presets,
fixtures with edge cases and documentation (THEME.md).

* Validation: `npm run cms -- theme validate themes/reference-theme-v1`
* Site check: `npm run cms -- site validate --theme themes/reference-theme-v1`
* Tests: `npm test` (see `tests/themes/reference-theme.test.ts`)
