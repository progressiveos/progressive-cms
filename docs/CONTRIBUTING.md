# Contributing

Issues and pull requests are open for review. A contribution is not automatically accepted; maintainers review correctness, security, compatibility and maintenance cost. Progressive OS maintains product direction and the official release process.

## Before opening a pull request

1. Search existing issues and pull requests, then open an issue for a substantial bug or proposed change.
2. Keep changes focused and include a reproduction or clear rationale. Do not include credentials, personal data, private reports or customer backups.
3. Run the checks relevant to the change and describe the exact commands and results. Do not claim a check that was not run.
4. Sign off each commit using DCO 1.1. For example:

   ```sh
   git commit -s -m "docs: clarify installation"
   ```

The sign-off records that you have the right to submit the contribution under the license stated for the project. Contributions accepted into the first-party project are offered under Apache License 2.0. There is no required Contributor License Agreement (CLA). Read the [Developer Certificate of Origin 1.1](https://developercertificate.org/) and the project's [license information](licensing.md).

Pull requests are reviewed before merge. Opening one does not promise acceptance, a release date, or a particular product direction.
