# Changelog and release notes

## Progressive CMS 1.0 Public Beta

**Status:** prerelease, not stable 1.0.0. The current technical version is listed in the [documentation index](index.md) and release metadata.

The Public Beta provides a self-hosted CMS with a native Linux installer, browser Admin, REST API, CLI, MCP interface and editable Liquid themes. Public documentation includes complete interface maps and first-party Skills for site building, content work, SEO and technical privacy readiness. Optional extensions are versioned separately.

The release supports declared Content Types, RichText v2, Block Document v1, revision-based editing and publication, theme activation/history, navigation, media, forms, search and SEO metadata. See the [documentation index](index.md) for the contracts and limitations of each area.

The accepted deployment target is Ubuntu 26.04 with systemd, Node.js 24 and PostgreSQL. Exact requirements and tested database versions are listed in [Requirements](requirements.md). Read the matching release's installation instructions and verify its SHA-256 before installing. The installable ZIP is different from GitHub's generated source archive.

This release does not automatically update existing sites. Back up an installation and review the exact release's compatibility and update instructions before upgrading.
