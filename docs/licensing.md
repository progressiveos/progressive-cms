# Material provenance and distribution scope

This documentation and its examples were prepared for inclusion as a public documentation folder at the Progressive CMS project owner's request. This does not grant a license to the private Core repository or its Git history.

Public prose and synthetic company examples were authored for this repository. Content Contract guidance adapts the accepted contract with [historical provenance](compatibility.md). OpenAPI/schema artifacts are first-party public contract metadata from the pinned Core source. Starter heading/text/form/breadcrumb Liquid fragments originate in the first-party reference theme; this repository records their origin.

No external fonts, stock imagery, CDN libraries, customer data, private reports or backup sets are included. Synthetic theme fixture data is an authoring example required by Theme Contract validation, not a private application test harness.

See [reference notice](reference/NOTICE.txt). The release folder preserves provenance/attribution and uses approved project distribution terms; no additional open-source license for Core is inferred.
