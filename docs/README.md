# Progressive CMS public documentation

Start at [index.md](index.md) for the current product release. This folder is copied into the release as `docs/`. It contains Markdown guides, public Agent Skills, their local references and the public schemas/examples used by the instructions.

The official [site-builder Skill](skills/progressive-cms-site-builder/SKILL.md) is self-contained and is also prepared at source-release root `skills/`. See [agent installation](agent-skills.md) for Codex, Claude Code and Copilot. The English chapters are primary; Russian chapters under `ru/` are partial.

The product version in `release-version.txt` is independent of Skill versions, compatibility minimums and historical feature introductions. See [release inclusion](release-copy.md) for the automated release gate.
