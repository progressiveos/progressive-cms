# Release and compatibility

<!-- cms-current:start -->
Current Progressive CMS release: **RC34** (`1.0.0-rc.34`).
<!-- cms-current:end -->

This product release is associated with these instructions, not a value to impose on a server. Read `server.cms_version` and `server.release_id` from bootstrap. The minimum supported CMS/contracts are in [manifest.json](../manifest.json); they are compatibility boundaries, not the current release. The Skill's own version is independent.

The exact Core source input, documentation commit and artifact pins are recorded in the immutable metadata for each release; they are separate pins. Preparing a later release refreshes its label without claiming a new content/runtime acceptance. No private Core workspace is needed.
