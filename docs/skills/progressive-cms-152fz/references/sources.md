# Источники и актуализация

Проверка источников: **2026-10-19**. Это дата подготовки, а не срок действия заключения. При каждом реальном выполнении проверь актуальную вступившую в силу редакцию, исключения и изменившиеся сервисы. Будущую редакцию закона не применяй до её вступления. Полный текст закона на сайте Минтруда содержит изменения по июнь 2025; более позднее изменение статьи 12 проверяется отдельно по официальной публикации. Не используй эту копию как доказательство отсутствия дальнейших изменений.

Во время подготовки некоторые страницы pravo.gov.ru/ФСТЭК и последующие страницы Кремля не отдавались через доступные fetch-инструменты. Это отражает доступность источника, не отмену нормы. Не приписывай непроверенной странице прочитанное содержимое; укажи, что сверялось по полному официальному тексту Минтруда/реестру изменений и что требует повторного получения. В частности, профиль средств защиты/уничтожения должен подтвердить ответственный специалист до технической приёмки соответствующих строк.

В отчёт включай фактическую дату, URL, статью/пункт, требование, результат и evidence. Технические выводы о Progressive CMS основаны на публичных формах/analytics/theme API и чтении их реализации; установленная версия может отличаться. Перепроверь capabilities/сеть/права, не доверяй одному номеру продукта.
