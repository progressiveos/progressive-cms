# Support

For a reproducible product defect, open an issue in the [Progressive CMS repository](https://github.com/progressiveos/progressive-cms/issues). Include the exact release version, deployment profile, expected and observed behavior, sanitized error codes and steps to reproduce. Remove passwords, tokens, private URLs, personal data and database exports before sharing logs.

Use the [documentation index](index.md), complete [interface maps](index.md#contracts-and-tasks), and the installed instance's `cms agent bootstrap --json` output to identify the actual version and capabilities. Optional Extensions may have their own support and license terms.

For project or commercial enquiries, use the [Progressive CMS contact page](https://p-cms.com/contacts/). Public issue support has no response-time SLA. Do not use public issues for vulnerability reports; follow the [security policy](SECURITY.md).
